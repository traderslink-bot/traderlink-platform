## Writing Rules

All generated content should remain markdown only unless the user explicitly asks for implementation.

Do not create or edit unless explicitly requested:

- JSX
- HTML
- CSS
- React components
- Next.js pages
- Production route files
- Production schema files
- Production website files

Every article draft should include YAML frontmatter and should follow the SEO writing system prompt and quality checklist.
