# Discord Beta Landing Page Plan

## Goal

Create the public share link `traderslink.pro/beta` for the free Discord beta.
It explains the available tools before a visitor chooses to continue with
Discord, then sends them to the dashboard-host Discord sign-in flow.

## Approved design

- Blue full-page background.
- A large raised white frame on desktop.
- The existing dark-blue Beta App card inside that white frame.
- White stacked feature cards inside the dark-blue card.
- The Beta card action block at the bottom uses the three-line membership
  message **Free access for / TradersLink Discord / Members** and retains the
  existing **LOG IN NOW!** sign-in button. Its headline is 50% larger on desktop
  only.
- Below the sign-in button, retain button-height-or-greater vertical space,
  then show **Not a TradersLink Discord member? / Anyone can join for free!**
  and a **Join Free Discord** button linking to the public invite.
- The public homepage header CTA reads **Join Free Beta** and links directly to
  `https://traderslink.pro/beta`.

## Boundaries

- Do not alter public homepage content other than the approved header CTA, or
  dashboard root behavior.
- Do not change Discord OAuth, newsletter consent, account data, or Academy
  progress in this slice.
- Preview through Railway staging before any production release.
