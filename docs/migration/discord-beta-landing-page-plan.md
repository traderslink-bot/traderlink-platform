# Discord Beta Landing Page Plan

## Goal

Create the public share link `traderslink.pro/beta` for the free Discord beta.
It explains the available tools before a visitor chooses to continue with
Discord, then sends them to the dashboard-host Discord sign-in flow.

## Approved design

- Blue full-page background.
- A large raised white frame on desktop.
- The existing dark-blue Beta App card inside that white frame.
- White stacked feature cards inside the dark-blue card.
- One action at the bottom: **Continue with Discord**.

## Boundaries

- Do not alter the public homepage or dashboard root behavior.
- Do not change Discord OAuth, newsletter consent, account data, or Academy
  progress in this slice.
- Preview through Railway staging before any production release.
