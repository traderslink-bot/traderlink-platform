# Scanner title view dropdown

November 12, 2026. Top Gainers and Momentum use a single title-row dropdown for Table, Cards and Two rows. In Cards, the same panel contains Indicators and Catalyst checkboxes, order controls, and the existing indicator/timeframe settings. The chart drawer's scanner cards and full scanner views use the same control. No extra control row remains in the card body.

Expanded indicator details use the current reading's color and color each recorded signal separately. Bullish is green, bearish red, and neutral orange. Numeric gain/loss coloring remains in the preceding scanner color slice. No production deployment.
