# Scanner indicator signal age

November 12, 2026. Scanner ticker cards retain their current EMA alignment and show the latest crossover separately for 15 elapsed minutes on 1m, 5m and 15m. Expanded indicator details use the same window and show relative ages. The shared clock updates the visible age and expires the event even when no new trade candle arrives. Watchlist signal history and scanner qualification are outside this change.

Private browser QA with a simulated clock verified that the 5m crossover updates from 30s ago to 1m ago, expires at 15 minutes without a new candle, and leaves the current alignment visible. Focused tests cover all three timeframes. No deployment.

Mobile performance QA used Chromium at 390px and 4× CPU throttling, with 40 populated scanner cards and 280 indicator readings. The first paired run identified broad indicator rerenders on clock updates. The revised timer updates only the event labels, and closed details remain unmounted. With scanner updates held steady and all 40 fresh badges changing together, the 10.5-second timer-enabled samples contained one long task each (74 ms and 101 ms), compared with zero in the timer-disabled samples. No additional candle requests occurred. The mobile browser crossover/expiry check, 20 focused tests and file lint passed. This is an emulated stress test. The Help Center requires no change for the rendering optimization.
