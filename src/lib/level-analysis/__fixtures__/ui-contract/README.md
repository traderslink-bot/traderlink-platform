# Execution Level Context UI Contract Fixtures

## Purpose

This directory contains compact JSON fixtures for the neutral
`ExecutionLevelContextUiContract` shape. Future journal UI work can use these
fixtures to render factual level-context states without inventing unsafe labels,
scoring, coaching, recommendations, or trade advice.

## Fixture States

- `available-ui-contract.json`
- `limited-ui-contract.json`
- `unavailable-ui-contract.json`
- `not-replay-safe-ui-contract.json`

The states cover the primary display cases future screens need before they
render real stored read models.

## Generation

Fixtures are generated by:

```text
src/lib/level-analysis/__fixtures__/ui-contract/generate-ui-contract-fixtures.ts
```

The generator uses existing pure builders from the level-analysis adapter,
attachment, storage, observation read-model, and UI contract modules. It starts
from the compact `LevelAnalysisSnapshot` v1 fixture and derives each contract
state deterministically.

To update the fixtures after an intentional contract change, run:

```text
npx tsx src/lib/level-analysis/__fixtures__/ui-contract/generate-ui-contract-fixtures.ts
```

Then run the fixture tests before committing.

## Intended Use

Future UI components may use these fixtures to verify display behavior for:

- available factual context
- limited factual context with missing optional facts
- unavailable context
- context that is not replay safe

The fixtures are display contracts only. They are not execution-analysis inputs
and do not change execution-analysis behavior.

## Boundaries

Do not infer:

- trade grades
- coaching
- P/L
- giveback
- behavior scoring
- recommendations
- entry or exit decisions
- trade advice

Synthetic continuation-map content remains factual forward-planning context
only. Quality, diagnostics, and limitations remain context only.
