# Trade Detail Level Facts UI Contract Fixtures

Compact fixtures for gate
`journal_level_analysis_delivery_trade_detail_level_facts_ui_contract`.

These fixtures lock the UI-facing contract shape for the trade detail level
facts display. They are facts-only and intentionally exclude raw source
payloads, persisted trade-link internals, resolver state, scoring, coaching,
P/L, giveback, behavior scoring, recommendations, and trade-advice fields.

The live trade detail page is not wired in this gate.
