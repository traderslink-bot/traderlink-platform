# Execution Level Context UI Contract Fixtures

## Purpose

This fixture pack gives future UI work stable examples of the neutral
`ExecutionLevelContextUiContract` states before any React components are built.

The fixtures are factual display contracts derived from the locked
`LevelAnalysisSnapshot` v1 app-side pipeline. They do not introduce scoring,
coaching, P/L, giveback analysis, behavior scoring, recommendations, trade
advice, or execution-analysis behavior changes.

## Fixture List

The fixtures live in:

```text
src/lib/level-analysis/__fixtures__/ui-contract/
```

Files:

- `available-ui-contract.json`
- `limited-ui-contract.json`
- `unavailable-ui-contract.json`
- `not-replay-safe-ui-contract.json`

## Fixture States

- `available`: factual context is present, replay safe, and not limited.
- `limited`: factual context is replay safe but has missing optional facts or
  other limitations surfaced in the contract.
- `unavailable`: factual context is missing or unavailable.
- `not_replay_safe`: factual context exists but no-lookahead safety is false.

## Generation Process

Fixtures are generated by:

```text
npx tsx src/lib/level-analysis/__fixtures__/ui-contract/generate-ui-contract-fixtures.ts
```

The generator uses the existing pure app-side builders:

- snapshot adapter
- snapshot attachment
- snapshot storage
- execution level context input
- observation read model
- UI contract builder

This keeps the committed JSON aligned with the real contract shape.

## Future UI Usage

Future journal UI work may use the fixtures to render factual display states
for:

- overview
- nearest levels
- extensions
- synthetic continuation-map context
- quality context
- diagnostics
- limitations
- safety
- data completeness
- source identity

UI components should treat fixture values as read-only display data.

## Forbidden Interpretations

Future UI must not infer or display:

- grades
- coaching
- P/L
- giveback
- behavior scoring
- recommendations
- buy/sell/hold decisions
- entry or exit decisions
- trade advice
- mistake or discipline labels

These fixtures are for factual inspection only.

## Synthetic Continuation-Map Treatment

Synthetic continuation-map content remains forward-planning context only. The
fixtures preserve synthetic counts, marked status, `synthetic_forward_planning`,
`historicalEvidence: false`, and the
`not_historical_support_resistance` limitation.

Synthetic rows are not historical support/resistance evidence and are not
execution instructions.

## Quality Diagnostics And Limitations

Quality warnings, diagnostics, and limitations are displayed as context. They
may explain coverage or safety state, but they must not become scoring or user
guidance.

## Update Process

When an intentional UI contract change lands:

1. Regenerate the fixtures with the generator command.
2. Run the fixture test.
3. Run TypeScript.
4. Run the full suite.
5. Review the JSON diff for factual wording and section boundaries.
