# TradersLink Landing Page

Minimal Vercel deploy project for the public TradersLink beta landing page.

This folder intentionally contains only the marketing page and its animated
hero canvas. It avoids the main Trader Intelligence app routes, API routes,
SQLite persistence, and local levels-system dependency while the full product
continues to be built locally.

## Local Checks

```bash
npm install
npm run check
```

## Deploy

Deploy this folder as the Vercel project root.
